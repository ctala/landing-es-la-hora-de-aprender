## 🎯 Resumen Ejecutivo

En este episodio inaugural de **"Es la hora de aprender"**, Cristian Tala, Diego Arias y Rodrigo Rojo discuten OpenClaw: una herramienta revolucionaria que permite crear agentes de IA personalizados que funcionan como verdaderos asistentes virtuales.

### Highlights del episodio:

- **🤖 OpenClaw explicado**: Qué es, cómo funciona y por qué es diferente a ChatGPT
- **💰 Costos reales**: Desde $6/mes (VPS) hasta $100/mes (Claude Max)
- **⚙️ VPS vs Mac Mini**: Pros y contras de cada opción
- **📊 Casos de uso**: Automatización de contenido, gestión de tareas, desarrollo de plugins
- **🚨 Impacto laboral**: 50% de trabajos automatizables en Chile (estudio 2024)
- **🔮 Futuro**: One-person billion dollar companies ya son posibles

## 🎓 Conceptos Clave Mencionados

| Concepto | Descripción |
|----------|-------------|
| **OpenClaw** | Framework open-source para crear agentes de IA personalizados con memoria persistente |
| **VPS** | Virtual Private Server - servidor virtual en la nube (~$6/mes) |
| **Mac Mini** | Hardware físico local para correr modelos de IA (~$700 + RAM 24GB mín.) |
| **N8N** | Herramienta de automatización workflow (alternativa a Make/Zapier) |
| **Claude Max** | Plan premium de Anthropic ($100/mes, acceso a Opus) |
| **LLM Local** | Large Language Model ejecutado en hardware propio (privacidad) |
